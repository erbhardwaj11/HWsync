# HWsync

WordPress plugin & synchronization engine for PC hardware components and real-time multi-vendor pricing across Indian computer retail stores.

## Features
- Multi-vendor scrapers and data adapters (MDComputers, Vedant Computers, PrimeABGB, EliteHubs, PCStudio, etc.)
- Canonical component database schema (wp_hwsync_components)
- Normalized vendor price tracking (wp_hwsync_vendor_prices)
- Intelligent normalization and component matching engine
- Automatic post-sync WordPress Post/CPT publishing with live price comparison tables
